# IOS XR Hands-on Guide

This guide is a hands-on walkthrough of Cisco IOS XR lab exercises: how configuration is staged and committed, how processes and memory are observed, how task groups control authorization, and which debugging commands to use.

Work through the chapters in order. Each chapter states a goal, then uses numbered steps, parameter tables, and verbatim CLI from the original lab notes.

| No. | Chapter | Description |
| --- | --- | --- |
| 01 | [Commit configuration](01-commit-configuration/index.md) | Target configuration, `commit`, best-effort and confirmed commits, exclusive sessions, and rollback |
| 02 | [IOS XR processes](02-ios-xr-processes/index.md) | Job ID, process ID, and thread ID, including an ISIS process restart |
| 03 | [Memory leak detection](03-memory-leak-detection/index.md) | Snapshot-based memory compare and related `show memory` commands |
| 04 | [Task groups](04-task-groups/index.md) | User groups, custom task groups, and AAA privilege checks |
| 05 | [Useful debugging commands](05-useful-debugging-commands/index.md) | Traces and CLI/shell history commands |
